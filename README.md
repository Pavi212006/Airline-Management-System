**Airline Management System**
A foundational learning project exploring the intersection of Python and SQL. This application simulates a basic airline backend to manage flights and track delays.

**Key Learning Objectives**
 * Database Design: Implementing Primary and Foreign keys to link Airports, Flights, and Delays.
 * Data Persistence: Using SQLite to store data locally in a .db file.
 * SQL Logic: Writing JOIN queries to retrieve human-readable data from multiple tables.
 * Version Control: Practicing the industry-standard workflow using Git and GitHub.

**Built With**
 * Python 3.x
 * SQLite3
 * Git Bash (MinGW64)

**Project Structure**
 * AirlineManagementSystem.py: The main Python script containing the application logic.
 * AirlineManagementSystem.sql: The SQL script used to initialize the database tables.
 * airline.db: The local database file generated by the script.

**How to Run**
 * Ensure Python is installed on your computer.
 * Run the following command in your terminal:
   python AirlineManagementSystem.py
 * The database will initialize automatically from the provided .sql file on the first run.
